# 从零开始学 - 坐标系转换

在3D视觉中，坐标系不再像2D视觉中那样通常都只有像素坐标系（例如opencv中，图像是左上角为原点，x轴为横向向右，y轴为竖直向下），自动驾驶中主要包含的坐标系有：世界坐标系，车辆坐标系，lidar坐标系，相机坐标系，像素坐标系。他们之间可以相互转换，一般情况下是从3D到3D，2D到3D，3D到2D等不同的方式，我们先来看这些坐标系的定义，然后再来看如何进行转换。

# 相机坐标系、图像坐标系、像素坐标系

## 针孔相机模型Pinhole Camera Model

![image.png](%E4%BB%8E%E9%9B%B6%E5%BC%80%E5%A7%8B%E5%AD%A6%20-%20%E5%9D%90%E6%A0%87%E7%B3%BB%E8%BD%AC%E6%8D%A2%201bd3135fac17814b8c63cbe8f7d39cfb/image.png)

针孔相机模型（不是针孔相机）是用来描述3D空间中的一个点坐标，经过一个理想化的针孔相机，投影到2D平面上的数学关系表示。这个针孔相机假设光圈是一个点，并且没有镜头聚集光线。具体来说，针孔相机模型可以通过相似三角形原理求出3D到2D的转换。

![image.png](%E4%BB%8E%E9%9B%B6%E5%BC%80%E5%A7%8B%E5%AD%A6%20-%20%E5%9D%90%E6%A0%87%E7%B3%BB%E8%BD%AC%E6%8D%A2%201bd3135fac17814b8c63cbe8f7d39cfb/image%201.png)

**坐标系：**

**C**：相机的**光心**位置

**CXYZ坐标系：相机坐标系**，这是一个3D坐标系，其中C为原点，相机向右为X轴正向，相机向上为Y轴正向，光心向前为Z轴正向，坐标单位是mm或m

**RX’Y’坐标系：图像坐标系**，这是一个2D坐标系，描述物体在成像平面的位置，其中R为原点，R是光轴与图像平面的交点，也叫做主点（principal point）或者图像中心（image center），向上为Y轴正向，向右为X轴正向，坐标单位通常是mm。

**OUV坐标系：像素坐标系**，这是一个2D坐标系，表示物体在数字图像中的位置，其中O（左上角）为原点，向右为U轴正向，向下为V轴正向

**p：** 3D空间中的一个点，在相机坐标系下可以表示为(x, y, z)

**q：** p点经过光心投影到2D图像平面中的点，在图像坐标系下可以表示为(x’, y’)，经过转换可以得到像素坐标系下的像素坐标位置(u，v)

**投影关系：**

我们从不同视角观察上图，可以得到2D的投影关系：

同理，可以得到

![image.png](%E4%BB%8E%E9%9B%B6%E5%BC%80%E5%A7%8B%E5%AD%A6%20-%20%E5%9D%90%E6%A0%87%E7%B3%BB%E8%BD%AC%E6%8D%A2%201bd3135fac17814b8c63cbe8f7d39cfb/image%204.png)

通过相似三角形原理，我们可以求出2D相机坐标系下q点的坐标：

- $x'=-\dfrac{f}{z}x$
- $y'=-\dfrac{f}{z}y$

3D到2D的坐标转换，通常会经过上述的**投影，**再接一个**180度的旋转**

我们可以用两种方式来理解这个旋转180度：

1. 将坐标系旋转180度
2. 假设有一个虚拟的图像平面，距离光心的距离不是-f，而是f（也就是在光心前方）例如下图：

![image.png](%E4%BB%8E%E9%9B%B6%E5%BC%80%E5%A7%8B%E5%AD%A6%20-%20%E5%9D%90%E6%A0%87%E7%B3%BB%E8%BD%AC%E6%8D%A2%201bd3135fac17814b8c63cbe8f7d39cfb/image%205.png)

通常在实现的时候，例如数码相机，我们可以在读取pixel的时候，就按照旋转后的顺序来读取，这样得到的图像就已经经过旋转了。

所以，在旋转180度之后，3D到2D图像坐标系的投影关系可以写成：

- $x'=\dfrac{f}{z}x$
- $y'=\dfrac{f}{z}y$

可以写成齐次坐标表示：

$$
z\begin{bmatrix} x' \\ y' \\ 1\end{bmatrix} = \begin{bmatrix} f && 0 && 0 \\ 0 && f && 0 \\ 0 && 0 && 1\end{bmatrix} \begin{bmatrix} x \\ y \\ z\end{bmatrix} 
$$

图像坐标系到像素坐标系的转换：

$$
u =\dfrac{x'}{dx} + c_x
$$

$$
v =\dfrac{y'}{dy} + c_y
$$

其中：

**u,v**：像素坐标

$c_x, c_y$：主点在像素坐标系下的位置（通常是作为硬件参数给出）

$dx,dy$：像素的物理尺寸（单位为 mm/pixel），也就是，一个像素点，在图像坐标系下的长度是多少mm（通常是作为硬件参数给出）

同样，可以将上面的公式写成齐次坐标形式：

$$
\begin{bmatrix} u \\ v \\ 1\end{bmatrix} = \begin{bmatrix} 1/dx && 0 && c_x \\ 0 && 1/dy && c_y \\ 0 && 0 && 1\end{bmatrix} \begin{bmatrix} x' \\ y' \\ 1\end{bmatrix} 
$$

最后，将像素坐标系投影带入到3D到2D图像坐标系投影中可得：

$$
z\begin{bmatrix} u \\ v \\ 1\end{bmatrix} = \begin{bmatrix} 1/dx && 0 && c_x \\ 0 && 1/dy && c_y \\ 0 && 0 && 1\end{bmatrix} \begin{bmatrix} f && 0 && 0 \\ 0 && f && 0 \\ 0 && 0 && 1\end{bmatrix}\begin{bmatrix} x \\ y \\ z \end{bmatrix} 
$$

将 $f/d_x,f/dy$分别写成：$f_x,f_y$，然后经过合并可以得到从**相机坐标系到像素坐标系的投影**关系：

$$
z\begin{bmatrix} u \\ v \\ 1\end{bmatrix} = \begin{bmatrix} f_x && 0 && c_x \\ 0 && f_y && c_y \\ 0 && 0 && 1\end{bmatrix} \begin{bmatrix} x \\ y \\ z \end{bmatrix} 
$$

其中，$f_x,f_y,c_x,c_y$组成的矩阵，因为他们都是和相机硬件相关的参数，通常是提前给定的，所以这一部分也叫做**相机的内参(camera intrinsic)**

## Lidar坐标系(Lidar)， 车辆坐标系(Ego)，世界坐标系(World)

![image.png](../%E4%BB%8E%E9%9B%B6%E5%BC%80%E5%A7%8B%E5%AD%A6%20-%20%E6%99%BA%E9%A9%BE%E5%9F%BA%E7%A1%80%EF%BC%9ANuScenes%20%E6%95%B0%E6%8D%AE%E9%9B%86%201bd3135fac1780e6a232c1a227160f03/image.png)

如上图中所示的Nuscenes数据集的传感器分布以及其对应的坐标系，可以看到：

- 各个Sensor都有自己的位置和坐标系
- **Lidar（Top）坐标系**：是原点在LIDAR传感器中心，x轴向右，y轴向前，z轴向上的坐标系。
- **IMU坐标系**：通常情况下会将IMU坐标系作为**主车坐标系（ego）**，其原点是IMU中心（车辆后轴中心），x轴向前，y轴向左，z轴上上。
- 相机坐标系：如上图，这里需要注意，每个相机都有自己的坐标系。
- 另外还有**世界坐标系**, 并未在上图中画出

**世界坐标系(World coordinate system)**

世界坐标系用于描述相机和物体的位置，使用右手笛卡尔坐标系（就是三维直角坐标系，满足右手定则，这样三维空间中的任何一点，都可以用（x,y,z）表达其位置）。自动驾驶中，世界坐标系通常为车辆在第一帧时的位置作为参考系（例如IMU开机后第一个时间戳接收到的消息），在Nuscenes数据集中，**世界坐标系被定义为当前地图的左上角为原点，向右为y轴正向，向下为x轴正向的坐标系。**

### 坐标系转换：

![image.png](%E4%BB%8E%E9%9B%B6%E5%BC%80%E5%A7%8B%E5%AD%A6%20-%20%E5%9D%90%E6%A0%87%E7%B3%BB%E8%BD%AC%E6%8D%A2%201bd3135fac17814b8c63cbe8f7d39cfb/image%206.png)

在自动驾驶的车上，不同的传感器都安装在不同的位置，而且不同的传感器也都有各自的坐标系。因此，同一个物体，在不同的传感器坐标系下，有不同的坐标，感知常常需要在这些传感器之间进行转换和对齐，就会用到坐标系转换计算。获得传感器之间的转换关系的过程通常叫做标定。

**坐标系转换的基本原理：**

如上图所示，坐标系的转换通常是两个步骤：

1. 旋转（rotation）
2. 平移（translation）

上面的这两步，可以通过外参，进行矩阵运算得到坐标系的，假设旋转矩阵为R，平移向量为T：

$$
P_{lidar} = R\cdot P_{cam} +T
$$

上面的公式就可以表示从cam坐标系到lidar坐标系的转换。写成齐次坐标形式为：

$$
\begin{bmatrix} P_{lidar} \\ 1 \end{bmatrix} = \begin{bmatrix} R && T \\  0 && 1 \end{bmatrix} \begin{bmatrix} P_{cam} \\ 1\end{bmatrix}
$$

如果要得到**反向**的转换：

$$
P_{cam} = R^{-1}\cdot P_{lidar} - R^{-1}T
$$

具体的旋转平移计算方式，可以参考上一篇[从零开始学 - 矩阵旋转平移基础](%E4%BB%8E%E9%9B%B6%E5%BC%80%E5%A7%8B%E5%AD%A6%20-%20%E7%9F%A9%E9%98%B5%E6%97%8B%E8%BD%AC%E5%B9%B3%E7%A7%BB%E5%9F%BA%E7%A1%80%201bd3135fac17815e9696f6e74e6f03d6.md) 

### 常见的坐标系：

**图像坐标系：**

```python
           up  z front
            |    ^
            |   /
            |  /
            | /
            |/
left ------ 0 ------> x right
            |
            |
            |
            |
            v
          y down
```

**Lidar坐标系（mmdet3d库）：**

```python
             z up  x front
               ^    ^
               |   /
               |  /
               | /
               |/
y left <------ 0 ------ right
```

**Nuscenes Lidar-TOP 坐标系（也是mmdet3d的深度坐标系）：**

```python
          z up  y front
            ^    ^
            |   /
            |  /
            | /
            |/
left ------ 0 ------> x right
```
