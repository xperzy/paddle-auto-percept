# 从零开始学DETR (6) - 优化目标：集合匹配 Loss 和匈牙利算法

在目标检测、目标跟踪等任务重，训练过程往往需要对预测结果与真实标注（Ground Truth, GT）进行一一匹配，从而计算loss并模型进行训练。在DETR中，为了更好地学习全局特征表示，采用了基于集合匹配的 Loss 函数和匈牙利算法来动态确定匹配关系。

本章节将从基本概念出发，逐步讲解基于集合匹配的 Loss 和匈牙利算法的原理。

# 问题

在目标检测任务中，模型经过检测头之后会输出一组预测，包含预测框和类别信息，训练时的真实标注是一组真实框。我们需要一种方法，将这一组预测框与一组真实框进行匹配，以便计算loss。

通常，预测框的数量和真是框的数量不一致（预测框>>真实框），因此我们的问题转变为：

1. **在预测框和真实框之间找到一个最优的匹配关系**
2. **利用这个匹配关系定义并计算Loss，进行模型优化（训练）**

# 集合匹配

集合匹配就是在两个集合之间建立最优的一对一映射。通过定义一个匹配成本（Matching Cost），在所有可能的匹配方案中，选择成本最小的方案。

匹配成本，可以通过成本矩阵来表示，即每一个预测框和每一个真实框两两之间成本（cost）。目标是找到一个匹配方案 ，使得总匹配成本最小。

在DETR检测任务中，我们当然是希望预测框和真实框越接近越好，这个“接近”，可以从框的位置、物体的类别等方面进行衡量。因此，匹配成本越低，可以理解为，框和框越“接近”，将这些描述数值化，就是我们需要的Loss函数了。

在DETR中，这个问题可以定义为：

**输入：**

- $P = \{p_1, p_2, ..., p_N\}$：预测框和类别分布
- $G = \{g_1, g_2, ..., g_N\}$：GT框和类别

**目标：**

找到最小成本的匹配方案

**输出：**

最佳匹配方案：$\sigma(i)$，表示对于每一个预测框$p_i$匹配的GT框$g_{\sigma(i)}$

# 匈牙利算法

匈牙利算法是一种经典的优化算法，用于解决二分图上的最小权匹配问题。DETR采用了匈牙利算法来计算预测框和GT框的匹配。

## 匈牙利算法的步骤：

1. 构建匹配成本矩阵：
    1. 由两部分构成：分类成本和边界框成本
    2. 最终的匹配成本：
        1. $C_{i,j}=\lambda_{cls}\cdot C_{cls}(p_i,g_i) +\lambda_{box}\cdot C_{box}(p_i,g_i)$
        2. 分类成本：$C_{cls}(p_i, g_j)=-log(p_{i}^{cls}[ g_j^{cls}])$
        3. 边界框成本：$C_{box}(p_i, g_j) = ||p_i^{box} - g_j^{box}||_1 - \mathrm{GIoU}(p_i^{box}, g_j^{box})$
2. 归一化：对于成本矩阵$C$
    1. 行归一化：每行减去该行的最小值，确保每行至少一个零
    2. 列归一化：每列减去该行的最小值，确保每列至少一个零
3. 最大独立零匹配
    1. 在矩阵$C$中，寻找一个独立零元素集合，保证每行和每列最多有一个零被选中，且总匹配的零数量最多。
    2. 这里的独立零是指：一个零所在的行或者列都没有其他已经被选中的零，这个零称为独立零
4. 调整矩阵
    1. 找出未覆盖的行和被覆盖的列
    2. 在未覆盖的行中找出最小值
    3. 在矩阵中：未覆盖的行减去这个最小值，被覆盖的列加上这个最小值
5. 重复
6. 生成匹配方案

**在DETR的代码实现中，匈牙利算法是直接调用scipy库中的linear_sum_assignmeng方法来实现的。**

# DETR中的Loss计算：

DETR的损失函数由两个主要部分组成：

- **分类损失（Classification Loss）**：用于评估模型对检测物体的分类能力。
- **双向匹配损失（Bipartite Matching Loss）**：DETR使用双向匹配方法将预测与真实目标进行配对，这一方法与传统方法有所不同。
- **边界框回归损失（Bounding Box Loss）**：用于衡量预测的边界框与真实边界框的匹配程度。

此外，还有一个**辅助损失（Auxiliary Loss）**，它进一步规范化网络，帮助稳定训练过程。

## 分类损失

由于DETR不使用锚点，模型直接预测一个集合，集合中的每个元素对应图像中的一个物体。为DETR采用了交叉熵损失函数作为分类损失，目标是最小化预测标签与真实标签之间的差距。

分类损失的计算步骤如下：

- 对于每个预测框，计算概率分布。
- 使用交叉熵损失计算预测和真实类别的差距。

假设目标类别为 $y_{true}$，预测的概率分布为 $p_{pred}$，则分类损失$L_{cls}$ 为：

$L_{cls} = - \sum_{i} y_{true}^{i} \log(p_{pred}^{i})$

其中，$i$ 是类别索引，$y_{true}$ 是目标的真实标签，$p_{pred}$是预测的类别概率。

## 双向匹配损失

DETR的另一个关键创新是使用**双向匹配**方法来将预测的物体与真实标签进行配对。传统的目标检测方法依赖于预定义的锚点来进行匹配，而DETR通过匈牙利算法（Hungarian Algorithm）来进行高效的匹配。

双向匹配损失包括两个方面：

- **正样本匹配（Positive Match）**：预测与真实目标之间的匹配。
- **负样本匹配（Negative Match）**：预测与不存在物体的背景区域之间的匹配。

匹配过程基于以下标准：

1. 预测框和真实框之间的GIOU（Generalized Intersection over Union）值。
2. 匈牙利算法确保最优匹配，以最小化总损失。

在最终的损失计算中，DETR对匹配正确的预测框施加了一个较小的分类损失，并且对未能正确匹配的预测框（即背景区域）施加了一个较大的损失。

具体来说：

1. 计算每对框的GIoU值：
2. 这些GIoU值被用来构建匹配的代价矩阵，每个元素为 1-GIoU来表示，再加上分类损失作为元素的值
3. 使用匈牙利算法，找到最小匹配代价
    1. 也就是找到一组匹配方案，使得每一个真实框和预测框都有唯一匹配，同时代价最小

由于DETR使用了 **固定数量的预测框**（通常为 N 个），并且每个框都会与真实框进行匹配，但真实框的数量 M 可能远小于预测框数量。因此，会存在一些**空白的预测框**（没有真实框与之匹配）。这些空白的预测框通常被视为背景类，并且会分配一个“虚拟”目标标签。其处理方式如下：

- **背景类匹配：** 对于没有与任何真实框匹配的预测框，DETR会将其视为“背景”目标。这些框的分类损失将被计算为背景类的损失，且边界框回归损失被设置为一个常量（通常为0）。这样，模型能够通过这些背景类的标签来处理未匹配的预测框。

## 边界框回归损失

**边界框回归损失**用于衡量预测边界框与真实边界框之间的差距。DETR采用**平滑L1损失**（Smooth L1 Loss）来回归边界框的四个参数：中心点坐标（x, y）和宽度、高度（w, h）。具体来说，平滑L1损失函数对于回归问题提供了更好的鲁棒性，尤其是当预测值和真实值相差较大时。

平滑L1损失的计算如下：$L_{bbox}(t, p) = \sum_{i \in \{x, y, w, h\}} \text{SmoothL1}(t_i - p_i)$

其中，t 是真实的边界框坐标，p 是预测的边界框坐标，i表示坐标轴。

SmoothL1的计算公式可以理解为一个分段函数，在[-1, 1]区间内和其他区间范围使用不同的计算方式：

$$
SmoothL1(x-y) = \begin{cases} 0.5 *(x-y)^2 / \beta && if\ |x-y| < beta\\ |x-y|-0.5*\beta && otherwise \end{cases}
$$

## 总损失函数

DETR的最终损失函数是分类损失、边界框回归损失和正负样本匹配损失的加权和。总损失函数可以表示为：

$L_{total} = L_{cls} + \lambda_{bbox} L_{bbox} + \lambda_{giou} L_{giou}$

其中，$\lambda_{bbox}$和 $\lambda_{giou}$ 是超参数，用于调节分类损失和回归损失的权重。

通过联合优化这些损失，DETR能够在不依赖锚点的情况下，直接进行目标检测的训练和推理，且能够处理复杂的物体关系和位置预测。
