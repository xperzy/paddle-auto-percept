# 从零开始学DETR (5) - 分类与回归：DetHead

DETR中，Object Query在经过Decoder之后，得到了num_queries个包含了目标位置、类别等信息的特征向量，这些特征向量将作为输入给到接下来的检测头中，检测头负责将这些特征转换为障碍物的具体类别，以及目标框的位置和大小。

# 检测头

### 分类头：

将每个目标查询映射到类别概率分布

- 输入：[N, num_queries, embed_dim]
- 输出：[N, num_queries, num_classes+1]（+1表示背景类）
- 操作：一个简单的全连接层 Linear(embed_dim, num_classes+1)

### 框回归头：

对每个目标查询预测边界框的归一化坐标[x, y, w, h]

- 输入：[N, num_queries, embed_dim]
- 输出：[N, num_queries, 4] （分别表示归一化厚的预测框中心点坐标和长宽）
- 操作： 由多个Linear层和激活层组成的MLP结构：
    - Linear1(embed_dim， embed_dim)
    - ReLU()
    - Linear2(embed_dim， embed_dim)
    - ReLU()
    - Linear3(embed_dim， 4)
    - Sigmoid()，将坐标归一化到`[0, 1]`

# 后处理

### 训练时的后处理

1. **目标匹配**:
    - 使用 **匈牙利匹配算法** 将 `num_queries` 个预测与真实目标进行一一匹配。
    - 匹配时综合考虑 **分类损失** 和 **边界框回归损失**，匹配成本为两者的加权和。
2. **损失计算**:
    - 对匹配到的目标：
        - **分类损失**: 使用交叉熵损失，评估预测类别与真实类别的差距。
        - **边界框损失**: 包括 L1 损失和广义 IoU (GIoU) 损失，用于评估预测框与真实框的位置差异。
    - 对未匹配的目标：
        - 仅计算其分类损失，将其视为背景类。
3. **损失优化**:
    - 总损失由分类损失、L1 损失和 GIoU 损失的加权和组成，通过反向传播优化模型参数。

### 推理时的后处理

1. **分类和框预测**:
    - 从分类头输出中选择置信度最高的类别（非背景类）。
    - 从框回归头输出中得到归一化的边界框坐标 `[x_min, y_min, x_max, y_max]`。
2. **过滤低置信度预测**:
    - 根据设定的置信度阈值（`threshold`），过滤掉置信度较低的目标。
3. **直接输出结果**:
    - 返回剩余目标的边界框及其类别，通常包括：
        - 边界框坐标 `[x_min, y_min, x_max, y_max]`
        - 目标类别及其置信度
